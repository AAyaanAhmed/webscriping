# Web Scraping Program

This project is a simple Python web scraper that collects book information from a publicly available website. The extracted data is stored in a CSV file for later use.

The scraper retrieves the book title, price, and availability using HTTP requests and HTML parsing. The collected information is automatically written to `books.csv`.

Run the program using:

`python web_scraper.py`

Requirements

Python 3.x

requests

beautifulsoup4

Install the required packages:

`pip install requests beautifulsoup4`
